2. Grammar — Some & Any

✅ Some

Generally positive sentences mein use hota hai.

I have some money.

There are some apples on the table.

She bought some vegetables.


❌ Any

Generally negative sentences aur questions mein use hota hai.

I don't have any money.

There aren't any apples.

Do you have any water?


Easy Rule 🧠

Positive → Some
Negative → Any
Question → Any

Examples:

I have some friends. ✅

I don't have any friends. ✅

Do you have any friends? ✅

4. Reading Practice 📖

1. Where did Aman go?


2. Who went with him?


3. What did Aman order?


4. How was the food?
