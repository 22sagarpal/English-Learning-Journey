2. Grammar – There is / There are

इनका इस्तेमाल किसी जगह पर मौजूद चीज़ों के बारे में बताने के लिए होता है।

There is → एक चीज़

There is + singular noun

There is a book on the table.

There is a computer in the room.

There is a fan in the classroom.


There are → एक से ज्यादा चीज़ें

There are + plural noun

There are two books on the table.

There are three students in the room.

There are many chairs in the classroom.



---

3. Negative Sentences

There isn't → एक चीज़ नहीं है

There isn't a computer here.

There isn't a fan in the room.


There aren't → कई चीज़ें नहीं हैं

There aren't any books here.

There aren't any students in the classroom.

4. Questions

Is there...?

Is there a computer in the room?

Is there a book on the table?


Yes, there is.
No, there isn't.

Are there...?

Are there any students in the classroom?

Are there two chairs here?


Yes, there are.
No, there aren't.
