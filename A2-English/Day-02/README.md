2. Grammar: Comparative Adjectives

Comparative ka use do cheezon ki tulna karne ke liye hota hai.

Structure

Subject + be + adjective + er + than + object

Examples

Delhi is bigger than Meerut.

A train is faster than a bus.

This book is cheaper than that book.


Irregular Comparatives

Good → Better

Bad → Worse

Far → Farther


Examples

English is better than before.

This result is worse than last time.

4. Reading Practice

Read:

> Last summer, Ravi visited two cities, Delhi and Jaipur. He found Delhi bigger than Jaipur, but Jaipur was cleaner and quieter. He enjoyed both cities, but Jaipur was more beautiful because of its historical buildings.



Questions

1. Which city was bigger?


2. Which city was cleaner?


3. Which city was quieter?


4. Why did Ravi like Jaipur?


5. Did he enjoy both cities?
