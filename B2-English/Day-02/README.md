2. Grammar – Present Perfect Continuous Tense

Structure

Subject + has/have been + Verb-ing + since/for + time

Examples

I have been studying English for two years.

She has been working since morning.

They have been learning Python for six months.

We have been waiting for an hour.


Negative

I have not been studying.

She has not been working.


Questions

Have you been studying English?

Has she been working here?
