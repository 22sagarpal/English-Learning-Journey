2. Grammar – Conditionals

Zero Conditional (Facts)

If + Present Simple, Present Simple

If you heat water, it boils.

If it rains, the ground gets wet.


First Conditional (Real Future)

If + Present Simple, will + Verb

If I study hard, I will pass the exam.

If you practice English, you will improve.


Second Conditional (Imaginary)

If + Past Simple, would + Verb

If I had a million rupees, I would start a business.

If I were rich, I would travel the world.


Exercise

Translate:

1. Agar main mehnat karunga, to exam pass karunga.


2. Agar tum English practice karoge, to fluency improve hogi.


3. Agar mere paas car hoti, to main office drive karta.


4. Agar paani 100°C tak garam hota hai, to woh ubalta hai.


5. Agar mere paas zyada samay hota, to main aur books padhta.
