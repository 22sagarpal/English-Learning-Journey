3. Grammar: Cleft Sentences

Used to emphasize a particular part of a sentence.

Normal:

I learned English through daily practice.

Cleft:

It was through daily practice that I learned English.

Examples:

It was Sagar who solved the problem.

It is communication that matters most.

What I need is more speaking practice.
