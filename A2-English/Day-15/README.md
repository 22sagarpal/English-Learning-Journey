2. Grammar — There is / There are

Kisi jagah par kisi cheez ke hone ke baare mein batane ke liye.

Singular → There is

There is a book on the table.

There is a chair in my room.

There is a garden behind my house.


Plural → There are

There are two chairs in the room.

There are many books on the shelf.

There are three windows in my bedroom.


Negative

There isn't a TV in my room.

There aren't any chairs here.


Questions

Is there a bathroom upstairs?

Are there any books on the table?


🧠 Easy Rule:

1 thing → There is
2+ things → There are
