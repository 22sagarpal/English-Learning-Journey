2. Grammar: First Conditional

Structure

If + Present Simple, Future Simple (will + verb)

Examples

If I study hard, I will pass the exam.

If it rains, I will stay at home.

If you practice English daily, you will improve quickly.


Negative

If I do not study, I will not pass.

If she does not work hard, she will not succeed.


Practice
